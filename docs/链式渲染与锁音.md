# 链式渲染与台词锁音（2026-09-28）

> 解决用户反馈的两个问题：**「分镜衔接对不上」**、**「嘴说话对不上」**。

## 1. 问题与根因

| 现象 | 根因 |
|---|---|
| 分镜衔接对不上 | 每镜**独立生成**：参考图只锁住"还是同一个人"，镜头之间是硬切，景别/机位/光位/姿态各写各的；末段还常出现冻结帧 |
| 嘴说话对不上 | 角色镜走 `MiniMaxH3ReferenceToVideo`，该节点**没有 AUDIO 输入**（`/object_info` 实测只有 clip/prompt/宽高/参考图）→ 角色镜物理上无法被台词驱动，只能让模型自己编声。附带后果：部分镜头音轨静音（实测 37 镜里 3 镜被判不合格） |

## 2. 方案：社区成熟工作流 + 确定性混音

装 [`ComfyUI-MiniMaxH3-TimelineDirector`](https://github.com/Songssx/ComfyUI-MiniMaxH3-TimelineDirector)
（零 pip 依赖）到 `ComfyUI/custom_nodes/`，用它的 `TimelinePlanner → FiniteSegmentSampler`
把**同场景连续镜头合成一条链，一次 ComfyUI 执行**生成：

```
TimelinePlanner(timeline_data) → FiniteSegmentSampler(重叠帧 + 原生 AV latent 续接)
→ CreateVideo → SaveVideo
```

出片后按去重边界**切回逐镜 clips** —— 指纹 / manifest / 质检 / 胶片条 / 合成全部照旧。

### 2.1 帧几何（踩过的坑，写死在 `vm/chain.py:geometry`）

H3 要求每段帧数 = `5 + 17n`、重叠 = `5 + 17k`（5/22/39/56）。所以：

```
段长   = 计划帧 + 重叠 − 5        ← 不是「计划帧 + 重叠」！(163 帧不合规，节点包直接报错)
新内容 = 段长 − 重叠 = 计划帧 − 5  ← 每镜只损失 5 帧（0.21s）
总输出 = Σ计划帧 − 5 ×(镜数−1)
```

### 2.2 音频：**不要**用社区的 `audioMode="locked"`

实测该标记在本机**不保留原音**：成片音轨与输入配音的包络相关只有 **0.378**
（是模型重新生成的、时间大致对齐但内容不同）。所以改成**确定性混音**：

1. 逐镜 TTS（H3 原生语音栈，复用现有权重，零额外下载；一句中文约 5 秒）
2. 各句摆在**本段新内容起点**（全局时间轴：0 / 前段累计…）合成一条 32kHz 立体声轨
3. 渲完 `ffmpeg` 把这条轨混进成片（视频流直接 copy）

> 没有台词的镜头用**静音轨**，绝不让模型自己编台词 —— 那正是"嘴说话对不上"的根源之一。

## 3. 实测证据（《西游记》第 1 章，1-3-01 → 1-4-01 → 1-4-02）

| 指标 | 结果 |
|---|---|
| 链渲染 | 3 镜一次执行 **125 秒**（分开渲约 140–150 秒且无连贯性）；总输出 328 帧 / 13.67s |
| 逐镜切片 | 5.1667 / 5.6667 / 2.8333 s，尾部剩余 **0 帧** |
| 切片间接缝 | 像素平均差 **1.2 / 1.0**（逐镜独立生成的原方案：69.6 / 78.4） |
| 链内原始接缝 | 帧间差 1.3–2.3（全片中位 1.01、最大 3.34）→ 接缝不是最抖的地方，肉眼无跳变 |
| 成片音轨 vs 台词 | 包络相关 **1.0000 / 0.9577 / 0.9544**（后两镜略低＝台词比镜头长被裁尾，见下） |
| 幂等 | 重跑 `--force` 之外一律「整链跳过（current）」 |

## 4. 开关与配置

| 配置项 | 默认 | 说明 |
|---|---|---|
| `chain_render` | `false` | 开启链式渲染。**ComfyUI 缺节点会自动退回单镜渲染并说明原因** |
| `chain_max_shots` | `3` | 每链最多镜头数（2–8）；越大越连贯、失败代价越大（链内全重渲） |
| `chain_overlap_frames` | `22` | 重叠帧数（5/22/39/56）；越大越稳 |

按项目开启：在 `projects/<项目>/project.json` 写 `"chain_render": true`。

## 5. 已知边界（别当成"已经完美"）

1. **H3 不是确定性口型求解器**（节点包文档原话）。本方案保证"说什么/字幕/时序"一致，**嘴型只是逼近**；要广播级口型必须出片后加专门唇形后处理（如 LatentSync 1.6）。
2. **每链第 2 镜起损失 5 帧**（0.21s），`sec_actual` 记的是真实值，拼片/字幕请一律以它为准。
3. **台词比镜头长会被裁尾**（如 1-4-01 台词 6.58s / 镜头 5.67s，相关 0.9577）。这是拆镜内容问题（该句 21 字超 20 字/句的软规则），应在 plan 阶段把它拆到连续两镜。
4. **链是原子的**：链内任一镜变动 → 整链重渲；链失败会**自动回退逐镜渲染**（宁可没连贯，不可没产物）。
5. 依赖社区节点包；`vm/chain.py:REQUIRED_NODES` 列了必需节点，缺任一即回退。

|---|---|
